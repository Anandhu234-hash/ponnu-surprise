# For Ponnu — Birthday + First Anniversary Website ❤️

Made for Ponnu by Achu. Date: 21 November 2026.

## Run on Kali Linux
1. Extract this ZIP.
2. Open Terminal in the extracted folder.
3. Run:
   ```bash
   python3 -m http.server 8000
   ```
4. Open Firefox at `http://127.0.0.1:8000`
5. Stop the server with Ctrl+C.
